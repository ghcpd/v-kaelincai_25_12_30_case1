# Role & Objective

You are a software engineer tasked with debugging and fixing a shift scheduling system, creating a corrected project version, and executing comprehensive validation to ensure all business rules are properly enforced.

## Background

This is an employee shift scheduling system for a factory production line managing work shifts with four critical business rules:

**Business Rules (All Must Be Enforced):**
1. Employees cannot work more than 6 consecutive days without rest
2. After a night shift (22:00-06:00), employees must rest at least 12 hours
3. Employees cannot exceed 48 hours of work per week
4. **Employees cannot have multiple shifts on the same day** (CURRENTLY BROKEN)

**Shift Types:**
- Morning: 06:00 - 14:00 (8 hours)
- Afternoon: 14:00 - 22:00 (8 hours)
- Night: 22:00 - 06:00 next day (8 hours)

**Original Project Structure:**
```
issue_project/
├── src/
│   ├── __init__.py
│   ├── models.py
│   ├── scheduler.py
│   └── validator.py
├── tests/
│   ├── __init__.py
│   ├── test_same_day_shifts.py
│   └── test_continuous_days.py
├── data/
│   └── sample_shifts.json
├── requirements.txt
├── README.md
└── KNOWN_ISSUE.md
```

## Inputs & Context

**Target Workspace:** Create relevant project files under the designated workspace directory with complete setup and configuration.

**Problem:** The system allows assigning multiple shifts to the same employee on the same day, violating the business rule requiring "one employee, one shift per day".

## Step-by-Step Instructions

### Step 1: Investigate the Bug
1. Run the tests to identify which scenarios fail: `pytest -v` in the original `issue_project/` directory
2. Examine the codebase to understand the validation workflow
3. Trace code execution from `scheduler.assign_shift()` through the validator
4. Identify why same-day shift validation is not working

### Step 2: Fix the Bug
1. Locate the root cause of the validation failure
2. Make the minimal necessary changes to fix the issue
3. Ensure your fix doesn't break other validations

Create a new directory `issue_project_fixed/` under the designated workspace with all corrected code:

### Step 4: Execute Full Project Validation

**4.1 Environment Setup:**
- Install dependencies: `pip install -r requirements.txt`
- Verify all required packages are available
- Configure Python environment if needed

**4.2 System Launch Verification:**
- Import core modules (`scheduler`, `models`, `validator`) to confirm no initialization errors

- Verify the system launches successfully without errors

**4.3 Automated Test Suite Execution:**
- Run full test suite with verbose output: `pytest -v`

**4.4 Runtime Smoke Test:**

**4.5 Comprehensive Reporting:**
