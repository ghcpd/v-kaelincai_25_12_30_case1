# Role & Objective

You are a software engineer tasked with debugging and fixing a shift scheduling system, creating a corrected version, and executing comprehensive validation to ensure all business rules are properly enforced.

## Background

This is an employee shift scheduling system for a factory production line managing work shifts with four critical business rules:

**Business Rules (All Must Be Enforced):**
1. Employees cannot work more than 6 consecutive days without rest
2. After a night shift (22:00-06:00), employees must rest at least 12 hours
3. Employees cannot exceed 48 hours of work per week
4. **Employees cannot have multiple shifts on the same day** (CURRENTLY BROKEN)

**Shift Types:**
- Morning: 06:00 - 14:00 (8 hours)
- Afternoon: 14:00 - 22:00 (8 hours)
- Night: 22:00 - 06:00 next day (8 hours)

**Original Project Structure:**
```
issue_project/
├── src/
│   ├── __init__.py
│   ├── models.py
│   ├── scheduler.py
│   └── validator.py
├── tests/
│   ├── __init__.py
│   ├── test_same_day_shifts.py      # Tests failing for same-day rule
│   └── test_continuous_days.py
├── requirements.txt
├── README.md
└── KNOWN_ISSUE.md
```

## Step-by-Step Instructions

### Step 1: Investigate the Bug
1. Run tests to identify failing scenarios: `pytest -v` in the original `issue_project/` directory
2. Examine the codebase to understand the validation workflow
3. Trace code execution from `scheduler.assign_shift()` through the validator
4. Identify why same-day shift validation is not working

### Step 2: Fix the Bug
1. Locate the root cause of the validation failure
2. Make minimal necessary changes to fix the issue
3. Ensure your fix doesn't break other validations

### Step 3: Create Fixed Version
Create a new directory `issue_project_fixed/` under the designated workspace with the corrected code:

```
issue_project_fixed/
├── src/
│   ├── __init__.py
│   ├── models.py
│   ├── scheduler.py
│   └── validator.py       # FIXED VERSION
├── tests/
│   ├── __init__.py
│   ├── test_same_day_shifts.py
│   └── test_continuous_days.py
├── requirements.txt
├── README.md             # Updated to reflect fixes
└── FIX_SUMMARY.md        # Document your fix
```

### Step 4: Execute Full Project Validation

**4.1 Environment Setup:**
- Install dependencies: `pip install -r requirements.txt`
- Verify all required packages are available

**4.2 System Launch Verification:**
- Import core modules to confirm no initialization errors
- Create a scheduler instance and verify basic operations work

**4.3 Smoke Test:**
- Assign a valid shift to an employee
- Attempt to assign a second shift on the same day
- Verify that `ValidationError` is raised with appropriate message

**4.4 Automated Test Suite:**
- Run full test suite with verbose output: `pytest -v`
- Verify all 12 tests pass
- Capture complete test output showing all test cases passing

**4.5 Runtime Behavior Verification:**
- Confirm the system launches successfully without import/runtime errors
- Verify business rule enforcement through test execution
- Ensure no errors, warnings, or exceptions occur during any phase
